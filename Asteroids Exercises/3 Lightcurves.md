# Lightcurves

## Background

In the exercise on magnitude and phase function, we have seen how the measured brightness of an asteroid changes over long timescales (weeks to months) due to its changing distance to the earth, distance to the sun, and phase. Asteroid brightnesses also change over short timescales (hours to days) due to rotation around their spin axes. In addition to revealing their rotational periods, light curves can also reveal information about an asteroid’s shape. 

In this exercise, we will work with light curve data from a variety of sources. Each dataset contains a brightness measurement (either a flux or a magnitude--you might need to convert between them!) and a date. This exercise also requires a small bit of python programming—make sure that you have the ability to edit and run python 3 scripts and ask for help early if needed. 

A note on dates: each brightness measurement is associated with a time, which will be reported in Julian Days (JD), a common unit used in astronomy which counts the number of days that have passed since January 1, 4713 BCE. As a result, the Julian Dates for contemporary observations are all larger than 2,000,000, and can be unwieldy. Using JD is computationally convenient, but can be unintuitive. You may wish to, before performing any data analysis, subtract from all times a constant “reference date” (such as the time of the earliest observation in your dataset or nearby round number) to reduce the number of digits needed to display any individual date. If you decide to do this, please note which reference date you are using. Many tools exist to [convert between JD and more familiar calendar dates](https://ssd.jpl.nasa.gov/tools/jdc/#/cd).

The Lomb-Scargle periodogram is a commonly used algorithm in astronomy to analyze periodic signals. The algorithm computes the power-frequency spectrum of a given dataset (the concept is similar to the idea of Fourier analysis, but adapted for needs of real-life datasets rather than idealized mathematical functions.) For a range of frequencies, the Lomb-Scargle periodogram displays the “power” of each frequency in the dataset—frequencies with high power are more present in the input dataset than frequencies with low power. Therefore, when trying to determine the rotation period of an asteroid, we can use the Lomb-Scargle periodogram to identify which frequencies of periodic signals in a given dataset have high powers. These are likely to correspond to the prominent underlying frequencies in the dataset (e.g. the frequency corresponding to the rotational period). For a more in depth introduction to the Lomb Scargle periodogram, see [Practical Lomb-Scargle](https://github.com/jakevdp/PracticalLombScargle/) by Jake VanderPlas.
