# Binder Instructions

One option for running these notebooks, if you are not comfortable installing Python on your own computer, is to run them in your web browser using Binder. To access this repository you can click [this link](https://mybinder.org/v2/gh/oriel-humes/open-asteroids/HEAD).

Using the file browser on the left, you can navigate to the notebook you would like to run and open it. Select the cell you wish to run and press Shift+Enter or the ► icon to run the code. You can also modify the code in place in your browser and re-run it to examine how the results change as you change the code. You may also upload your own files (such as your dataset) so that the program can read them by clicking the file folder icon > upward arrow icon and selecting a file from your computer, and download files generated by the code by right clicking them in the file browser and selecting 'Download'.
